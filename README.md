# Little Savings · 小小储蓄所

这是第一版可安装 PWA 原型，优先适配 Android 手机。

## 当前版本已经可以做什么
- 记录日常收入与支出（RM）
- 记录「原本想买但最后没买」的虚拟省钱金额
- 区分实际收支结余与虚拟存款
- 建立个人/共同储蓄目标，并记录贡献
- 在同一台设备上切换「我 / 她」演示账本
- 本机浏览器保存数据，刷新后仍在
- 支持 PWA 安装与基本离线打开

## 重要限制（请先看）
目前这是**单机原型**：数据保存在当前手机/浏览器的 localStorage。切换「我 / 她」只是演示，不是真正的双账号，也不会同步到另一台手机。请不要把它当作已经完成的双人云端账本，也不要用它存放高度敏感的财务资料。

要实现你们两台 Android 手机分别登录、互相查看对方账本，需要下一阶段接入 Firebase Authentication + Cloud Firestore，设置用户配对/邀请机制和数据库安全规则，再部署到 HTTPS 网站。这个压缩包没有包含真实 Firebase 项目凭据，也没有替你创建云端项目。

## 如何先在电脑预览
直接用浏览器打开 `index.html` 可以体验基本功能（PWA 安装和离线缓存需要通过 HTTPS 或 localhost）。

## 如何部署并安装到 Android
1. 将整个文件夹部署到支持 HTTPS 的静态网站托管服务（例如 Firebase Hosting、Cloudflare Pages 或 GitHub Pages）。
2. 在 Android Chrome 打开部署网址。
3. 选择 Chrome 菜单中的「安装应用」或「添加到主屏幕」。
4. 两个人各自在自己的手机安装。

注意：在云端同步尚未接好之前，两台手机的数据互不相通。

## 当前原型操作
- 点击右下角「记一笔」新增收入、日常支出或省钱记录。
- 在底部切换总览、账单、省钱存款、储蓄目标。
- 点击右上角圆形按钮切换演示身份。
- 在「储蓄目标」页面双击页面空白处，创建目标；目标卡片中可记录贡献。
